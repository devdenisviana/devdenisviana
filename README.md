## English

👋 Hello! I'm **Denis Jeronimo Viana Filho**.

💻 I am a software and hardware developer specializing in Embedded Systems, Microelectronics, and Mixed-Signal (AMS) Integrated Circuit Design. I also build full stack and backend web applications, from the database to the user interface.
My work focuses on low-level systems programming, real-time control, FPGA RTL design, and analog/mixed-signal IC modeling and simulation using the Synopsys EDA suite.

### 🚀 Featured Project: Kanban Full Stack

A deployed Kanban task manager with user accounts, boards, and drag-and-drop cards.

- **Live demo:** [kanban-fullstack-gold.vercel.app](https://kanban-fullstack-gold.vercel.app)
- **Source code:** [github.com/devdenisviana/kanban-fullstack](https://github.com/devdenisviana/kanban-fullstack)
- **Front end:** React, TypeScript, Vite, React Router, dnd-kit, react-i18next (English/Portuguese)
- **Back end:** Node.js, Express, TypeScript, Zod validation, JWT authentication, bcrypt
- **Database & deploy:** PostgreSQL (Neon) with Prisma ORM; Vercel (front end) and Render (API)

### 🔍 Current Focus

- **Mixed-Signal IC Design (AMS):** Analog and mixed-signal circuit design and simulation using **Synopsys Custom Compiler**, **PrimeWave Design Environment**, and **PrimeSim** — CMOS 90nm technology.
- **Digital Logic & FPGA:** RTL Design using Verilog, Intel MAX 10 (DE10-Lite), and Quartus Prime.
- **Digital Verification:** Functional simulation and debugging with **Synopsys VCS** and **Verdi**.
- **Embedded Firmware:** Bare-metal and FreeRTOS development for RP2040, ESP32, and STM32.
- **Full Stack & Backend Development:** Building and deploying web applications with **React**, **TypeScript**, **Node.js**, **Express**, and **PostgreSQL** (Prisma ORM).
- **Systems & Infrastructure:** Linux administration (Rocky Linux) and hardware-level network protocols.

### 📚 Areas of Expertise

- Analog & Mixed-Signal (AMS) Circuit Design: current mirrors, differential pairs, two-stage op-amps, folded cascode amplifiers, and bandgap voltage references
- CMOS Device Characterization: NMOS/PMOS DC behavior, PTAT/CTAT thermal response, ZTC compensation
- Electronic Design Automation (EDA) & IC Schematic/Layout flows
- Field-Programmable Gate Arrays (FPGA) & Hardware Description Languages (HDL)
- Systems Programming (C/C++)
- Internet of Things (IoT) architectures and Modbus/MQTT communication
- Real-Time Operating Systems (RTOS)
- Full Stack Web Development: REST APIs, JWT authentication, relational data modeling, responsive and bilingual (i18n) interfaces
- Computer Vision
- Kotlin development

### 🛠️ Synopsys EDA Stack

- **Custom Compiler** — schematic capture, layout, and mixed-signal design environment
- **PrimeWave Design Environment** — simulation setup, analysis, and results visualization
- **PrimeSim** — SPICE-class circuit simulation engine
- **VCS** — digital functional simulation (Verilog/SystemVerilog)
- **Verdi** — waveform debugging and analysis

**Synopsys Academic Certifications (Purple):** CMOS Fundamentals · VLSI Basics · Very-Deep Sub-Micron Fundamentals · Digital Design Fundamentals · ASIC Design Flow · Analog Foundation · Analog Comprehensive · Custom Compiler Introduction · Basic Layout Design and Schematic · PrimeWave Design Environment · Analog & Mixed-Signal Circuit and Layout Design Track

### 🎓 Current Program

CI-Expert (Universidade Federal do Ceará) — Mixed-Signal Track, applying the Synopsys AMS flow to progressively complex analog blocks: device characterization → current mirrors → op-amps → folded cascode → bandgap references.
